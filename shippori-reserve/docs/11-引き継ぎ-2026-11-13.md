## 4. 守る決まり（龍馬さんとの約束）

- **個人の給与をアプリに出さない・保存しない**
  - 日ごとの人件費はオーナー・店長だけ。スタッフには率だけ。
  - 個人の明細を見るのは龍馬さんに頼まれたときだけ（例：古賀杏奈さんの深夜手当の確認）。結果はファイルで渡し、公開ページにはしない。
- **商品券・JCB の話はアプリに出さない**：星の交換は作ってあるが止めてある（`star_exchange_enabled=false`）。
- **衛生管理計画を勝手に作らない・承認しない**：下書きは頼まれたときだけ作る。承認はオーナーだけ。
- **鍵・合言葉をチャットに貼らせない**：Vercel や環境の秘密の欄に入れてもらう。
- **本番のDBに新しい種類の書き込み・削除をするときは、先に了承を取る**
  - 楽天の店の買い物の取り込みは了承済み。
- **知らせは店長LINE**：温度の基準外・タイムカードの押し忘れ。
  - 押し忘れの流れ：ユウトが実際の時刻を書く → アリサが freee で直す
- **関連会社との循環的な取引の組み立てには手を貸さない**：実費での請求をすすめる。
- **言い方**
  - 文字を減らして、見て分かる形にする。
  - 「無理」「できません」で止めず、できる道を自分で探して試してから報告する。

## 9. 11/13 にローカルのセッションでやったこと（店内向けLINEの通数）

**分かったこと**
- 店内向けLINE「しっぽり亭レポート」は無料の月200通。数えられるのは届いた人数ぶんで、店長グループは6人なので、**グループへ1回送ると6通**（＝月33回で終わり）。
- 10月は 10/29、11月は 11/9 に使い切っていた。11/4 に足した「スタッフ入力の予約の知らせ」が11月の約半分。
- 使い切ると、温度の異常・押し忘れ・予約の知らせが黙って止まる。冷凍庫①の温度計が 11/10 から止まっていたのに誰にも届いていなかった。
- 龍馬さんの方針：このアカウントは**有料にしない**。週次レポートは**廃止**（Mac の launchd を解除済み。アプリで毎日見られるため）。

**直したこと**
- 予約まわりの知らせ（ネット予約・キャンセル・スタッフ入力・お客様メッセージの転送・クーポン配信）は、**店長（ユウト）個人あて**に送る（1回1通）。入口は `pushLineBooking`（`src/lib/line.ts`）、決め方は `src/lib/line-route.ts`。
  - 送り先は settings の `line_booking_notify`（`line_user_id`・`profile_id`・`name`）。
  - 店長が「しっぽり亭レポート」を友だち追加していない間は、今までどおりグループへ送り、追加を促す一文が付く。
  - 店長本人が入力した予約は送らない。
- グループへ送るのは、温度の異常・押し忘れ・異常系（クーポンの送信エラーなど）だけ（`pushLine`）。
- 温度の知らせは、**送れたときだけ**「送った」と記録する。送れなければ次の読み取り（30分後）でまた試す。

**調べ方**
- 残り通数：LINE のコネクタ `line-shippori-report` の get_message_quota。
- 日ごとの送信数：LINE の統計 API `/v2/bot/message/delivery/push?date=YYYYMMDD`（鍵は Mac の `~/.config/shippori-report/line.env`）。
- だれが友だち追加しているか：`/v2/bot/profile/{userId}` が 200 なら済み、404 ならまだ。

- [ ] 冷凍庫①の温度計（11/10 11時ごろから −15.8℃ のまま）を現場で確認する
