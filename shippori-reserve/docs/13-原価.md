# 原価（仕入・棚卸・ロス）

店主の要望（2026-11-05）「原価率削減システムは今の店舗管理システムの中に入れたい」の実装。
税理士の8月報告で原価率は 34.5%（前期 41.2%）。ただし消耗品費が 229,127円（売上の6.8%）に跳ねていて、
足すと約41.3%。月次の棚卸はまだしていない。日野さんの資料（原価管理の考え方）も参考にした。

## 場所と権限

- 売上タブ → 右上の **「原価」**（`/sales/cost`）。月末の棚卸は `/sales/cost/stock`
- 見る・入れる：オーナー・店長・事務（`cost.read` / `cost.write`）。スタッフ・閲覧のみには出ない
- 給与・人件費は一切扱わない

## 物差し

```
原価率 ＝（月初の在庫 ＋ その月の仕入 − 月末の在庫）÷ その月の売上
```

- 仕入も売上も **税抜**（税理士の月次報告と同じ）。食材は8%、店内の売上は10%なので、税込どうしで割ると約2ポイント低く出る
- 売上の税抜：店内（合計−物販）÷1.1 ＋ 物販÷1.08。売上は今の売上タブの実績（エアレジ）をそのまま使う
- 原価に入れるのは **食材＋酒・飲料**。消耗品は別に数え、「消耗品も入れると○%」として並べる
- **棚卸が月初・月末の両方そろうまで原価率は出さない**（「まだ出せません」＋足りないもの）。
  代わりに「仕入÷売上」を **目安** として出す。在庫の増減を無視した数字を原価率と呼ぶと、仕入れが多い月に誤った警報になる
- 月初の在庫＝前の月の **確定した** 棚卸。下書きの棚卸は使わない

## 入れるもの（3つだけ）

### 1. 仕入：書類の写真を撮る → AIが読む → 確認して保存

- 書類の種類は3つ：**納品書**／**請求書（月締め）**／**レシート**（現金・カード）
- 決めごと：**月締めの業者は月末の請求書を1枚だけ**。それ以外は納品書かレシート
- 1枚の書類を「食材・酒飲料・消耗品・その他」に分けて税抜で持つ（スーパーのレシートは食材と消耗品が混ざるため）
- 請求書は締め日（対象期間の終わり）で計上する
- 保存は必ず人が確認してから。AIは読むだけ。写真を横に出し、書類の合計（税込）と区分の金額がずれていれば警告
- AIが使えない（鍵が無い・読めない・止まっている）ときも写真は残し、手入力に切り替わる。記録は止まらない
- **二重の警告**（保存は止めない）：同じ業者の請求書と納品書・レシートが同じ月にある／同じ業者・同じ日・同じ金額が2件以上
- 写真を撮って「やめる」と、どの仕入にも使われていない写真は消す

AIの読み取り（`src/lib/cost-ai.ts`）：Claude API（`claude-opus-5-5`、effort low、JSONの形を指定、
拒否されたときの代わりのモデルは `fallbacks: "default"`）。1枚あたり数円の見込み。
鍵は Vercel の環境変数 `ANTHROPIC_API_KEY`（店主が設定。未設定なら手入力のまま動く）。

### 2. 月末の棚卸

- 品目（品名・単位・税抜の単価・食材か酒）を一度登録すれば、毎月は **数を入れるだけ**（先月の数も横に出る）
- **空欄＝数えていない（0とは別）**。0を入れれば0として数える
- 細かい調味料は「調味料まとめて（単位：円・単価1）」のように金額で1行にしてよい
- 「この数で確定する」で在庫額を固定。確定した月の数は DB が直させない（直すときは「確定を外す」）
- 数えた時点の単価を行ごとに持つので、あとで単価を直しても過去の在庫額は動かない

### 3. ロス（捨てたもの）

- 日付・品・金額（仕入値の目安・税抜）・理由（期限切れ／作りすぎ／調理ミス／傷み・破損／その他）・写真（任意）
- 原価率の計算には足さない（捨てた分はすでに仕入に入っている）。何をどれだけ捨てたかを見て、仕込み量・発注量を直すための記録

## DB（0065_cost.sql）

| 表 | 中身 |
|---|---|
| `cost_purchases` | 書類1枚＝1行。計上日・業者・種類・区分ごとの税抜額・税込合計・請求期間・写真・AIで読んだか。作った人／直した人は DB が入れる |
| `cost_stock_items` | 棚卸の品目と今の単価 |
| `cost_stocktakes` | 月ごとの棚卸（下書き／確定・確定時の在庫額） |
| `cost_stock_counts` | 月×品目の数と、数えた時点の単価。確定した月はトリガで書き換え不可 |
| `cost_losses` | ロス |

写真は非公開の置き場 `cost-photos`。表示は1時間だけ有効なURLをサーバーが作る。
毎日のバックアップ（`/api/cron/backup`）に5つの表を含めた。
