# 指標の仕分け（2026年8月の調査）

居酒屋で使われている経営指標をひと通り調べ、しっぽり亭の894日分の売上に
実際に当ててみた結果。**この店で意味があるものだけ**を残した。

調べた元の資料は `docs/research/kpi-01〜04`。実際に流したクエリは
`supabase/analysis/03_kpi_2026_08.sql`。店主向けの読み物にしたものは
[しっぽり亭 数字の読み方](https://claude.ai/code/artifact/7146a2a8-d9c2-43c1-8823-f0af9a0b96fe)。

## 実測で分かったこと

### 1. 谷は水曜だけではない（前回の訂正）

火曜（2026年4月からの定休）を除き、同じ曜日どうしの中央値で1〜7月を前年と比べた。

| 曜日 | 2025 | 2026 | 前年比 | 7か月ぶんの差 |
|---|---:|---:|---:|---:|
| 日 | 81,800 | 56,320 | **68.9%** | −688,000円 |
| 水 | 69,600 | 49,370 | **70.9%** | −587,000円 |
| 月 | 95,950 | 78,610 | 81.9% | −503,000円 |
| 木 | 80,400 | 67,285 | 83.7% | −393,000円 |
| 金 | 147,000 | 136,910 | 93.1% | −293,000円 |
| 土 | 130,500 | 129,515 | **99.2%** | −28,000円 |

合計 約−249万円（年換算 約−427万円）。**金土は守れていて、平日と日曜が落ちている。**
中身を見ると上振れが減ったのではなく「5万円に届かない日」が増えている
（水曜は29日中15日、前年は9日）。山を高くする話ではなく、谷を埋める話。

**ただし7月は前年比112.9%で反転している。** 落ち込みは1〜6月の話かもしれない。
8月・9月の数字で確かめる。

### 2. 曜日内のばらつき（CV）は 0.35〜0.50

金0.35・土0.36 が最小、日0.85 が最大。この水準だと、20%の効果を売上で検出するのに
片群で49〜63日かかる。**曜日を絞った施策を日商で検証するのは1年仕事**なので、
効果は施策そのものの数（申込数・出数・予約件数）で測る。

### 3. 太鼓祭り（10/16-18）は休業していた

2024年は3日とも売上の行が無い。2025年は10/16と10/18が行なし、10/17が10,000円。
金曜の中央値が14万円台なので、**この3日で毎年30万円前後の機会が消えている**。
店を開けずに折詰だけ売る、という手はまだ試していない。

## 仕分け

### いま出せる（売上と予約データだけで足りる）

| 指標 | なぜ |
|---|---|
| 同じ曜日・直近8回の中央値 | 25営業日の月商は何もしなくても±20%動く。前月比は見る価値がない |
| 予約の入り方（実数） | 率ではなく件数。月40件で「32.5%」には意味がない |
| 予約リードタイム（何日前に入るか） | 繁忙日が何日前に埋まるかが分かれば、席を止める判断ができる |
| 出勤1人あたりの日商 | いまのデータで唯一まともに動く生産性指標 |

### 席ログが3か月ぶん貯まってから

| 指標 | なぜ |
|---|---|
| **六人卓に実際は何人で座っているか** | 最重要。コーネル大の研究に、卓構成を客層に合わせただけで待ち時間を増やさず客数3割増を吸収した例がある。ばらつきが小さいので3か月で結論が出る |
| 人数別の実測滞在時間 | 標準滞在時間を勘から実測へ。行動が変わる唯一の分析 |
| 時間帯別の同時着席人数 | 山が19:30か20:30かでシフトの入り時刻が変わる |
| 席種別の余り | カウンター／テーブル／和室のどれが空いているか |

### 置くと害になる（この規模では作らない）

| やらない | 理由 |
|---|---|
| 客単価を主要KPIにする | 分母が手タップ由来。**タップが漏れるのは忙しい日**なので金土で系統的に過小になり、客単価が偽って高く出る。データを増やしても消えない |
| 36席を分母にした稼働率 | 4名が六人卓に座れば残り2席は物理的に売れない。永久に低く出て罪悪感だけ残る。測るなら「死に席」 |
| 売上の予測モデル | 信頼できる予測には最低12か月。実務の相場は「4週移動平均で十分」 |
| 曜日限定施策を日商で検証 | 20%の効果で片群8〜15か月。3か月では原理的に出ない |
| スタッフ別成績・待ち行列分析・多店舗比較 | 規模が違う |
| ダッシュボードに指標を足す | 定着しない原因の第一位が情報過多。Toastですらオーナー向けの入口は4指標 |

### 唯一の法則

調べた中で例外なく再現していたのはこれだけ ——
**自動で貯まるデータは使われ、手で入れるデータは使われない。**
Excelの売上管理は1〜2か月で止まる。トレタは自社の顧客台帳について
「使えていますか」というチェックリストを出している。席のタップも同じ構造の上にある。

## 最初の3か月の目標

「客数が分かるようになる」ではなく **「金土でもタップが続く運用ができている」**。

1. **記録率だけを見る** — レジの伝票数と席ボードの組数を毎日照合。
   金土の記録率が平日より明らかに低いなら、席ログ由来の分析はすべて保留。
   3か月経っても上がらなければ席ログは畳む（判断期限を先に決めておく）
2. **前月比をやめる** — 代わりに「同じ曜日・直近8回の中央値」と今日の位置
3. **ノーショー／直前キャンセルを流入元別に数える** — 比率データはばらつきが小さく、
   3か月できちんと結論が出る数少ないテーマ。業界ではネット予約＞電話予約とされる
4. **7/26の記録を書き起こす** — 本数・予約数・材料費・仕込み時間・残り。
   2026年はうなぎが安い年だったので、2027年の値付けはこれが唯一の手がかり
5. **谷は割引以外で埋める** — 一律割引は既存客の単価を下げるだけ、という点は日英で一致

## 物販をどこに置くか

**物販は席を使わないが、厨房の手を使う。** だから金土と12月にはぶつけず、
厨房に余力のある谷曜日に置く。

| 時期 | 催事 | 型 | なぜそこか |
|---|---|---|---|
| 2026-09-21 | 敬老の日の折詰 | 予約型 | 月曜＝谷。売上よりやり方を覚える1回目 |
| 2026-10-16〜18 | 太鼓祭りの弁当 | 要検証 | どうせ休業する3日間 |
| 2026-12-29〜31 | 年末オードブル | 予約型 | 忘年会の後の枠。受付11/1開始が業界標準 |
| 2027-02-03 | 恵方巻 | 予約型 | 水曜＝最弱曜日。2/2は火曜定休 |
| 2027-07-21 | うなぎ太巻き（一の丑） | 併用型 | 水曜。今年の日曜より店内を食わない |
| 2027-08-02 | うなぎ太巻き（二の丑） | 併用型 | 2027は二の丑がある年。月曜＝谷 |

成否は売上で測らない。見るのは4つ ——
**粗利の額**（率ではなく「通常営業の何日分か」）、**完売率**（95%以上）、
**予約比率**（70%以上あれば作る数が読めてロスが消える）、
**カニバリ差分**（その日の店内が同じ曜日の中央値からいくら下がったか）。

7/26で計算できたのは最後のひとつだけ。太巻き 622,500円 を差し引くと店内は約58,330円で、

- 同じ7月の他の日曜（134,940円・86,890円）より明らかに低い
- 直近5〜8月の日曜の中央値 71,290円 より 約13,000円 低い
- ただし2026年の日曜全体の中央値 60,765円 とは 約2,400円 しか違わない

比べられる日曜が2日しかないので、**カニバリがあったとは言い切れない**。
「疑いがあるので来年は必ず測る」までが今言えること。
（当初は日曜の平均を84,224円として「−26,000円」と書いていたが、
894日分から出し直したところ根拠が弱かったので訂正した。）
