# 6. 開発ロードマップ

## 0. 優先順位の考え方

**「今すぐ困っていること」から順に作る。**

しっぽり亭が今困っているのは、予約が5つの経路からバラバラに入ってきて、
どこにも一覧が無いこと。**まずそこだけを解決する。**

席割り当てルールも、流入元分析も、LINE連携も、
「予約が1画面に集まっている」状態が先に無ければ意味がない。

```
Phase 1  予約が1画面に集まる         ← ここまでで既に毎日使える
Phase 2  席とルールが管理できる        ← しっぽり営業の本題
Phase 3  ホームページから予約が入る     ← 流入経路の1つを自動化
Phase 4  数字が見える                 ← 経営判断の材料
Phase 5  LINEが自動で受信箱に入る       ← 手入力をさらに減らす
Phase 6  仕上げ                       ← 権限細分化・通知・Instagram
```

各フェーズの終わりに**必ず実店舗で使ってみて**、次に進む。
作り切ってから渡すのではなく、Phase 1が終わった時点で毎日使い始める。

### Instagram DM 連携について（正直な見通し）

依頼にある5経路のうち、**Instagram DM の自動連携だけは難易度が段違いに高い**：

- Instagram Messaging API（Meta Graph API）を使うには、
  **プロアカウント＋Facebookページ連携＋Metaアプリ作成＋アプリ審査（advanced access）** が必要
- 審査には用途説明・デモ動画・プライバシーポリシーの提出が要る。**数週間かかることがある**
- 仕様変更が多く、動かなくなるリスクも他より高い

**現実的な結論：Phase 1 の「スタッフが流入元＝Instagram DM を選んで手入力」で運用する。**
DMは1日数件のはずで、手入力の負担は小さい。集計は最初から正しく取れる。
自動化は Phase 6 で、**LINE連携が安定してから改めて費用対効果を判断する**。
（依頼どおり5経路すべてを1画面に集約する目的は、Phase 1 の時点で達成されている。
自動化されているかどうかは、集約されているかどうかとは別の話。）
