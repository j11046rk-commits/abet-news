# The Oldman — デザイン設計と判断理由

このダッシュボードは、**大人の男が葉巻とウイスキーを片手に開く画面** である。
業務ツールの見た目になった時点で失敗とみなす。

---

## 1. コンセプト

名前の由来である『老人と海』のヘミングウェイを軸に据える。
目指すのは **1950年代ハバナのプライベートクラブ**、あるいは古いウイスキーと葉巻のラベルが持つ
**印刷物の質感**。ラスベガスのカジノではない。**静かで、暗くて、金属の光沢がある。**

判断基準を3つに落とす。迷ったらこれで決める。

1. **紙か、画面か** → 紙。罫線・活字・余白で組む。UIパーツを増やさない
2. **光るか、鈍く反射するか** → 鈍く反射する。グローもシャドウも使わず、ヘアラインの明度で階層を作る
3. **喋るか、黙るか** → 黙る。文言は事実だけ。感嘆符と絵文字は使わない

---

## 2. カラートークン

この6色だけで組む。**7色目を足したくなったら、それは階層の作り方を間違えている。**

| 名前 | HEX | 用途 |
|---|---|---|
| `--ink` | `#0C0D0F` | 背景（ほぼ黒。純黒は避ける） |
| `--leather` | `#1A1512` | カード・サーフェス（オイルドレザーの褐色を含む黒） |
| `--brass` | `#B08D4F` | 主役のアクセント。真鍮。罫線・数値・アクティブ状態 |
| `--claret` | `#5A2028` | 警告・不足・支出（燻したボルドー） |
| `--paper` | `#E8E1D3` | 主要テキスト（純白は使わない。生成りの紙） |
| `--smoke` | `#7C766B` | 副次テキスト・ラベル（燻銀） |

派生は **同じ6色の透明度違いのみ** 許可する（例：`--brass-hairline: rgb(176 141 79 / 0.28)`）。
新しい色相は増やさない。

例外は **カレンダーの用途色2つだけ**。用途を色で弁別するという機能要件が、
6色では足りないため明示的に追加する。

| 用途 | 色 | 出所 |
|---|---|---|
| ポーカー | `--brass` | 既存 |
| ミーティング | `--smoke` | 既存 |
| プライベート | `--claret` | 既存 |
| 宿泊 | `#4A5A52` | 追加（深緑・トークン `--pine`） |
| その他 | `#3A3632` | 追加（消炭・トークン `--ash`） |

どちらも明度が低く彩度も低いため、既存6色のトーンを壊さない。

### ドロップシャドウは使わない

暗い画面では効かない。階層は **明度差と真鍮の 1px ヘアライン** だけで作る。
`box-shadow` は CSS 内で禁止（`--ring` によるフォーカスリングを除く）。

## 3. タイポグラフィ

| 役割 | 書体 | 指定 |
|---|---|---|
| ディスプレイ（見出し・数値の主役） | **Bodoni Moda** | 高コントラストのディドネ体。葉巻のバンドとウイスキーのラベルが実際に使う系統。大きく、字間を詰めて |
| 和文見出し | **Shippori Mincho** | |
| 本文（和文） | **Noto Sans JP** | |
| 本文（欧文） | **Inter** | |
| 数値・台帳 | **IBM Plex Mono** | 必ず `font-variant-numeric: tabular-nums` |

金額が縦に並ぶ画面なので、桁が揃わないのは許容しない。

### スケール — 中間を作らない

見出しは大きく、本文は小さく、その間を空ける。**中間のサイズを増やさない。**

| トークン | 値 | 用途 |
|---|---|---|
| `--fs-hero` | `clamp(3.5rem, 14vw, 6rem)` | 積立ゲージの金額（Bodoni Moda） |
| `--fs-display` | `clamp(1.75rem, 6vw, 2.5rem)` | 画面見出し |
| `--fs-body` | `0.875rem` | 本文 |
| `--fs-label` | `0.6875rem` | 字間を広げた大文字ラベル（`letter-spacing: .18em`） |
| `--fs-micro` | `0.625rem` | 補助・単位 |

`--fs-display` と `--fs-body` の間に何も置かない。これがこの画面の骨格になる。

## 4. 質感

- 全面に極めて微細な **フィルムグレイン**（SVGノイズを `opacity: .03` で重ねる）。
  `position: fixed` の擬似要素1枚、`pointer-events: none`
- **カードの上辺のみに真鍮のヘアライン**。葉巻のバンドを想起させる
- 角丸は **2px 以下**。ほぼ直角
- セクションの区切りは真鍮 1px 罫線 + 字間の広い極小の大文字ラベル（例：`LEDGER — 2026`）
  - 罫線はラベルの右側だけに伸ばす。左端揃えの活字組を守る

---

## 5. シグネチャー要素：積立ゲージ

ダッシュボードの主役。**ここにだけ大胆さを使う。**

グラスに琥珀色の液体が満ちていくように、月次目標に対する積立額を縦型ゲージで表す。

### 仕様

| 項目 | 値 |
|---|---|
| 形 | 縦長の矩形（グラスの側面）。幅 96px / 高さ 260px（モバイル）、コンテナ高さに追従 |
| 枠 | 真鍮 1px。角丸 2px。上端に一段細い真鍮のリング（ラベルの帯） |
| 液体 | `linear-gradient(#B08D4F → #8A6B33)` を下方向に |
| 液面 | SVG パスの正弦波。**周期 4.2s / 振幅 2.5px**。2本を位相差でずらして重ねる |
| 充填 | `達成率 = clamp(0, 積立額 / 目標額, 1)`。高さに 900ms `ease-out` でトランジション |
| 目標到達 | 液面が満ち、外周の真鍮リングが静かに点灯（`opacity` を 400ms で上げる。点滅させない） |
| 数値 | 液面の**横**に、達成額を `Bodoni Moda` の `--fs-hero` で。目標額は極小の `--smoke` で添える |
| 目盛 | ゲージ内側の右辺に 25% 刻みのヘアライン（4本）。数字は振らない |
| reduced-motion | 波を止め、静止した水平の液面にする。充填トランジションも無効化 |

### 実装メモ

SVG の `<path>` を `requestAnimationFrame` ではなく **CSS アニメーション** で動かす。
波形パスを横に2波長ぶん描き、`transform: translateX(-50%)` を 4.2s linear で無限ループさせる。
JS を毎フレーム回さないので、バッテリーにもタブ切り替えにも強い。

---

## 6. モーション

抑制的に。**200〜300ms、`ease-out`。**
ホバーは真鍮のヘアラインがわずかに明るくなる程度（`--brass-hairline` の alpha を .28 → .5）。
要素を飛び跳ねさせない。`transform: scale()` と `translateY` によるホバーは使わない。

例外は積立ゲージの充填（900ms）と液面の波（4.2s ループ）のみ。

---

## 7. 禁止事項（これをやったらやり直し）

- 紫〜青のグラデーション、ネオン、グロー
- Tailwind の既定色（特に `blue-500`, `slate-*` をそのまま使うこと）
- 絵文字アイコン、トランプのスートのイラスト、チップやサイコロのクリップアート
- 大きな角丸（`rounded-xl` 以上）のカードが並ぶ、いわゆる SaaS ダッシュボードの見た目
- クリーム色（`#F4F1EA` 付近）背景 + 高コントラストセリフ + テラコッタのアクセント
- 「Welcome back! 👋」のような馴れ馴れしいコピー

|---|---|
| あと ¥32,000 | もう少しで目標達成です！頑張りましょう |

## 9. 自己批評 — 既定値になっていないか

Phase 0 の最後に、上記の設計を「同種の依頼に対して自分が既定で出すもの」になっていないか
点検した。以下は **書き直した箇所とその理由** である。

### 9-1. ダークテーマ = カード + グロー + グラデーション枠、という手癖

**初稿**：カードに `border: 1px solid rgba(255,255,255,.08)` を四辺に回し、
アクセント色の淡いグローをホバーで載せる案を書いていた。

**問題**：これは「ダークUIといえばこれ」という汎用テンプレートそのもので、
葉巻のバンドでもウイスキーのラベルでもない。四辺の枠は画面をカード群の並びに見せ、
まさに禁止事項にある SaaS ダッシュボードへ寄る。

**書き直し**：**罫線は上辺のみ**に限定した（§4）。四辺を閉じないことで、
カードが「箱」ではなく「紙面のセクション」に見える。ホバーはグローをやめ、
ヘアラインの alpha を上げるだけにした（§6）。

### 9-2. 情報量を等価に並べる手癖

**初稿**：ダッシュボードを「KPIカード4枚 + グラフ + テーブル」で組んでいた。

**問題**：この施設が知りたいことは1つだけ（家賃を払えるか）なのに、
4枚のカードは4つの問いが等価にあるという嘘をつく。等価な並びは判断を助けない。

**書き直し**：積立ゲージを **ファーストビューの主役に単独で置き**、
不足額・あと何回・残り日数・1人あたりは、その下に **文章に近い密度の1ブロック** として従属させた
（SPEC §3-1）。KPIカードという単位そのものを設計から外している。

### 9-3. 「グラフ = ライブラリの既定」という手癖

**初稿**：月次推移に Recharts を採用しようとした。

**問題**：Recharts の既定はグリッド・軸ラベル・ツールチップまで含めて
「分析ツールの見た目」を持ち込む。この画面が持つべき質感と正面から衝突する。

**書き直し**：**自作SVG に確定**（SPEC §5）。軸は下辺の真鍮ヘアライン1本だけ、
グリッドは描かない、値は棒の上に `IBM Plex Mono` で直接置く。
描画に必要なのは月次12点の折れ線と棒だけで、ライブラリを入れる理由がない。

### 9-4. 中間サイズを刻む手癖

**初稿**：`text-xs / sm / base / lg / xl / 2xl` を素直に使う前提だった。

**問題**：中間サイズが揃っていると、すべての要素が「そこそこ重要」に見え、
紙面のコントラストが死ぬ。ヒエラルキーを言葉ではなくサイズの連続性で誤魔化すことになる。

**書き直し**：**タイプスケールを5段に固定し、`--fs-display` と `--fs-body` の間を空けた**（§3）。
中間が必要になったら、サイズではなく **字間と大文字化** で階層を作る（`--fs-label`）。

### 9-5. 「アイコンで意味を伝える」手癖

**初稿**：カレンダーの用途をアイコン（♠ / 💬 / 🏠）で区別する案があった。

**問題**：禁止事項に真正面から抵触するうえ、5種の用途に対して直感的なアイコンは存在しない。

**書き直し**：**色 + 字間を広げた極小の大文字ラベル**に統一（SPEC §3-3b）。
`POKER` `MEETING` のような組み方は、この施設が参照する印刷物のトーンとも一致する。

### 9-6. 「貸切」を色で強調しすぎる手癖

**初稿**：貸切バッジを `--claret` の塗り + 強めのコピーで扱い、一覧でも目立たせていた。

**問題**：仕様の意図は「罰則も上限も設けず、可視化だけする」こと。
貸切を赤く目立たせると、それ自体が咎めのサインになり、設計意図と逆に働く。

**書き直し**：貸切バッジは `--claret` の塗りだが **面積を極小に**、
メンバー画面の横棒では **貸切と通常利用を同じ太さ・同じスケールで併記** する（SPEC §3-5）。
色の違いだけで弁別し、大きさで序列をつけない。ソートは「多い順」にするが、
順位番号は振らない（ランキング化させない）。

### 9-7. トーン確認：暗い = 高級、という短絡

暗い配色は放っておくと「高級SaaS」にも「ゲーミング」にも転ぶ。
この画面をそのどちらでもなくしているのは、**Bodoni Moda の高コントラストな明朝**、
**四辺を閉じない罫線**、**フィルムグレイン**、そして **感嘆符のないコピー** の4点である。
実装中にこの4つのどれかを削りたくなったら、削らずに別の場所を削ること。
