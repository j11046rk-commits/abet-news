## Phase 3（予約フォーム + カレンダー）

- [x] フィクスチャを差し込んだプレビューで週表示・月表示・3日表示・予約一覧・予約フォームを撮影して自己批評。修正した点：
  - 週グリッドを 60dvh のスクロール領域に収め、開いた瞬間に 16:00 以降（この施設が動く時間帯）が見える位置へ自動スクロール。24時間ぶんをそのまま縦に伸ばすと、昼の10時間が死んだ余白になっていた
  - モバイル下部ナビが「カレンダー」「セッション」で2行に折り返していた。モバイルは和文のみ・nowrap、英字コードはデスクトップのみに変更
  - 貸切ブロック（塗りつぶし）の文字色を用途色の明度で出し分け。claret/pine/ash の上に `--ink` を置くと読めなかった
  - 用途の極小ラベルを ink 背景の上に置くと claret/pine/ash が暗すぎて読めないため、同じ色相を明るくした text 用の値を追加（DESIGN.md §2 の例外として明記）
  - 用途チェックボックスの色スウォッチを廃止し、和名 + 用途色の英字コードに統一（アプリ全体の表記と揃えた）
  - 「貸切希望」に独立した見出しを付け、用途タグの「プライベート」と視覚的に混同しないようにした
- [ ] ドラッグ選択は pointer イベントで実装。iOS Safari 実機での挙動は未確認（`touch-action: pan-y` を指定済み）
- [ ] 重複警告のための問い合わせはブラウザ側の anon クライアントから行う。RLS の select が通る前提
- [ ] 月表示のバーは日ごとに最大4本まで。それ以上は「+N」表記
